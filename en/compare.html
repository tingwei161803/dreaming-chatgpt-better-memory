ChatGPT vs Claude: two ways to dream

Same metaphor, two designs. OpenAI ships dreaming as an invisible background feature inside ChatGPT; Anthropic breaks it into parts developers assemble, tune and audit themselves — and publishes the research numbers. A point-by-point comparison of three primary sources.

01

The same intuition

Both define dreaming as looking back over past conversations while no one is waiting, so the next session starts with the right context. Anthropic names its inspirations outright: hippocampal replay during sleep, and the “sleep-time compute” idea from Letta and UC Berkeley.

02

Different audiences

ChatGPT dreams about you, the person: it happens automatically and you see a summary. Claude's cookbook dreams for your agent: the developer decides when it runs, which transcripts it reads and what shape the memory takes.

03

Different transparency

OpenAI shows its evals as charts with no citable figures and does not describe the architecture. Anthropic prints every prompt in full, reports measured costs, and publishes eval percentages.

Safety, privacy and cost
Prompt injectionNot discussed in the announcement.Transcripts are treated as data, never instructions. Analyzers hold five file tools only (read, write, edit, glob, grep), with no shell and an empty network allowlist; agents mount the result read-only.
Secrets and retentionNot discussed in the announcement; see OpenAI's Memory FAQ for controls.Credentials are never copied into memory. Managed Agents sessions aren't eligible for zero data retention or HIPAA, so the notebook deletes the session after exporting it. Every write is a memory version you can audit for 30 days.
CostAbout 5× less compute to serve Free users, alongside more memory capacity for Plus and Pro. Part of ChatGPT plans (Free included), not billed per run.Paid per run, at list price. 11 example transcripts (283 KB): $0.36, about 2.5 minutes. 50 long transcripts (about 12 MB): about $8, about 10 minutes. The run stops before starting if the estimate exceeds BUDGET_USD ($40 by default).
Review before useThe summary page is always there to look at.No review by default: a bad transcript can reach your agent the next morning. To review first, dream into a new store, read it, then switch the agent over.

What they share

  • Memory is made after the fact. ChatGPT no longer relies on “remember this”; Anthropic moves memory creation into the background so it doesn't pull the agent away from its task.
  • Time is a first-class problem. ChatGPT rewrites a trip once it's over; Claude's memory dates every fact and records what replaced what.
  • Memory is meant to be inspectable. ChatGPT has the summary page; Claude's memory is Markdown files plus a version history you can open.

Where they differ

Black box vs glass box

OpenAI describes what dreaming achieves, not how it works. Anthropic's cookbook prints its four prompt files in full and tells you which line to change for each behaviour.

Who pays and who sets the pace

With ChatGPT, cost is OpenAI's engineering problem (the ~5× cut is what makes Free possible). With Claude, the developer picks the schedule, the models and a budget ceiling, and sees the bill per run.

Threat model

Claude's design assumes transcripts may contain hostile text and limits every agent accordingly. OpenAI's announcement doesn't cover this. That doesn't mean ChatGPT lacks protections, only that the announcement doesn't describe any.

Our take

Editorial, not from the sources

The points below are this site's reading of the three sources, not claims made by OpenAI or Anthropic.

  • If you use ChatGPT: dreaming works out of the box. The useful habit is checking the summary page now and then, and using a Temporary Chat for anything you'd rather it didn't learn.
  • If you build agents: the cookbook is a template you can actually ship. The research post's lessons carry over to any memory system: tell the model what memory is for rather than how to write it, keep the always-loaded layer small, and pair a wiki with search.
  • Neither side has solved when to write memory, how to keep it current, or how often to dream. Anthropic lists all three as open questions at the end of its post.
